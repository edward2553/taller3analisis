# Title: taller 3

Aplicación de escritorio en Python (tkinter) que implemente Gauss-Seidel y Descomposición LU con cálculo de matriz inversa. Entregable como ejecutable .app para macOS y .exe para Windows via PyInstaller.

# Punto 1

## Description:
Desarrollar un programa amigable para el usuario en python, que permita resolver sistemas de ecuaciones lineales mediante el método de Gauss-Seidel.

## Criterios de aceptacion:

### El programa debe:

* Solicitar al usuario el número de ecuaciones.
* Permitir ingresar los coeficientes de la matriz AAA
* Permitir ingresar el vector de términos independientes bbb.  
* Permitir ingresar una aproximación inicial.  
* Permitir ingresar la tolerancia de error.  
* Permitir ingresar el número máximo de iteraciones.  
* Mostrar en pantalla los resultados de cada iteración.  
* Mostrar la solución final aproximada.
